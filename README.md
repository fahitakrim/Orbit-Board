**Orbit Board** is a private, high-performance Android virtual keyboard crafted with an authentic **Nothing OS & Bauhaus-inspired design language**. Featuring signature Matte Bauhaus aesthetics, Dot-Matrix typography, dynamic key accents, an interactive Real-Time Keyboard Resizer, and a complete **Native Bengali Typing Suite** (Avro Phonetic, Probhat, Jatiyo Modern, Jatiyo Classic, Alphabetical Bangla, and Instant Toggle Bengali Number Pad).

Zero internet permissions. Zero cloud logging. Zero tracking. Pure, elevated typing.
